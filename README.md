# Alloy Launcher releases

Downloads for [Alloy](https://alloy.axpect.xyz), a lightweight Minecraft: Java Edition launcher for Linux and Windows.

Get the latest version from the [Releases](https://github.com/SteelAspect/alloy-releases/releases) page:

- **Windows:** `Alloy_<version>_x64-setup.exe`
- **Linux (any distro):** `Alloy_<version>_amd64.AppImage`
- **Linux (small, uses your system WebKitGTK):** `alloy-launcher-<version>-x86_64.tar.gz`

Alloy updates itself from here. The source code lives in a separate repository.
